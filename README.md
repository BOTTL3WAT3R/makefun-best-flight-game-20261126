**Skyharbor Run** — an original flight game for the desktop browser. You fly the Kestrel K-7 bush plane on the Sable Coast air-mail run: take off from Skyharbor Field, thread seven glowing rings over the patchwork fields, the River Sable and the rooftops of Port Mina, watch your fuel, and put the aeroplane back on the north runway — gently. The chase view shows the coast in pseudo-3D with a lit instrument panel (airspeed, altimeter, artificial horizon, compass) and a HUD carrying altitude, speed and heading. Everything is drawn and sounded by the game's own code: procedural canvas art, synthesised WebAudio engine and wind, no assets, no network.

Play it: serve the `game/` folder with any static server (or run the included one) and open `game/index.html` in desktop Chrome. Steer with the arrow keys or the mouse, work the throttle with W/S or Shift/Ctrl, press F for flaps on approach, and mind the stall lamp.

## Run it

```sh
node serve.ts
# then open http://localhost:8091
# hand-in check: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
